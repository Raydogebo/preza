InsuranceCheck/ КАСКООБЗОР ПРИЛОЖЕНИЯ

Проверка страховых
документов

Тестовое приложение для предварительной проверки документов по КАСКО при повреждении стекла

02 / ПРЕДМЕТ ПРОВЕРКИ

Что проверяет приложение

Приложение анализирует пакет документов одного страхового дела.

Комплектность

Есть ли обязательные документы и какие из них отсутствуют.

Данные

Совпадают ли ФИО, ИИН, VIN и сведения о полисе в разных документах.

Даты и обстоятельства

Входит ли дата события в срок страхования. Есть ли противоречия в описании повреждения.

03 / СЦЕНАРИЙ РАБОТЫ

Как пользоваться приложением

Пользователь загружает документы и разбирает результат в карточке дела.

Загрузить пакет

Выбрать режим обработки и добавить PDF или ZIP с документами.

Получить результат

Дождаться проверки и открыть список недостающих документов и расхождений.

Проверить замечания

Перейти к оригиналу, оставить комментарий или дополнить пакет.

04 / РЕЗУЛЬТАТЫ

Какие результаты получает пользователь

После обработки приложение показывает итог и поясняет обнаруженные проблемы.

Комплект полный

Обязательные документы присутствуют, автоматические проверки пройдены.

Не хватает документов

Пользователь видит список документов, которые нужно добавить.

Ручная проверка

Есть расхождения, нечитаемые поля или вопросы, требующие сверки.

05 / РАБОЧЕЕ ПРОСТРАНСТВО

Что доступно в рабочем пространстве

Все действия по проверке собраны в карточке дела и общем списке проверок.

Поиск и история

Найти дело по ФИО, полису или названию. Отфильтровать дела по результату.

Данные и оригиналы

Посмотреть извлечённые значения и открыть исходную страницу документа.

Работа с делом

Добавить комментарий или документы. Скачать результат проверки в формате JSON.

06 / PDF И СКАНЫ

Как приложение работает с PDF и сканами

Доступны два режима обработки документов.

Демо

Проверяет текстовые PDF учебного корпуса локально. Сканы без текста не распознаёт.

OpenAI

Извлекает данные из PDF и изображений, в том числе сканов. Документы передаются в облако.

Условия работы

Для OpenAI нужны настройка доступа и разрешение на передачу. Данные со сканов требуют ручной сверки.

07 / ТЕСТОВАЯ ВЕРСИЯ

Границы тестовой версии

Версия предназначена для демонстрации сценария и проверки подхода.

Один сценарий

КАСКО при повреждении стекла. Для другого процесса нужно согласовать документы и правила.

Учебные примеры

Есть пакеты с полным комплектом, недостающими документами и расхождениями. Качество на реальных делах ещё не измерено.

Общий доступ

В размещённом пилоте участники используют общий логин и видят все дела. Личных кабинетов пока нет.
