# Контур — презентация-сайт

Девять адаптивных слайдов по презентации «Проверка документов по КАСКО».
Учебные данные; система не принимает решение о выплате.

## Просмотр

Откройте `index.html` в браузере. Зависимостей и сборки нет.
Для локального сервера: `python3 -m http.server 8080`.

- Стрелки ← / →, Page Up / Page Down — переключение слайдов.
- Home / End — первый / последний слайд.
- «Все слайды» — оглавление; у каждого слайда собственный адрес `#1`–`#9`.
- На телефоне доступны горизонтальные свайпы и прокрутка длинного слайда.
- Полноэкранный режим в поддерживающих его браузерах.
- Печать выводит все девять слайдов.

## GitHub Pages

Сайт готов для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Внешние шрифты, скрипты, аналитика и сетевые зависимости отсутствуют.

## Файлы

- `index.html` — содержание всех девяти слайдов.
- `style.css` — оформление, мобильная и печатная версии.
- `app.js` — навигация, оглавление, свайпы и полный экран.
