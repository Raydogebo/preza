# InsuranceCheck — обзор приложения

Сайт-презентация из восьми слайдов по `InsuranceCheck_Обзор_приложения.pptx`.
Содержание и логотип bcc hub перенесены из предоставленной презентации.

## Просмотр

Откройте `index.html` в браузере. Зависимостей и сборки нет.
Для локального сервера: `python3 -m http.server 8080`.

- Стрелки ← / →, Page Up / Page Down переключают слайды.
- Home / End открывают первый / последний слайд.
- «Все слайды» открывает оглавление. Ссылки на слайды: `#1`–`#8`.
- На телефоне доступны горизонтальные свайпы и прокрутка длинного слайда.
- Полноэкранный режим доступен в поддерживающих его браузерах.
- Печать выводит все восемь слайдов.
